CONTENT SAFETY

Changes can
be reviewed.

Every published update creates a GitHub commit. You can review the history of your website content and restore an earlier version through GitHub without rewriting it from scratch.

Repository history will be available after configuration.

  1. Open the content history link below when it has been configured.
  2. Choose a previous commit to see what changed in content/site.json.
  3. To restore an old version, ask a repository administrator to revert the published commit, review the resulting changes, and merge them into the main branch.
  4. GitHub Actions will rebuild the website after the revert is merged.

This guide does not claim to offer a one-click restore button. GitHub's commit/revert tools and branch permissions control restoration.
