Psalm 23 Transportation — new black & gold website

This is the functional implementation of the approved reference layout. It includes the transparent gold logo, scenic hero, business promises, boxed service and process cards, Christian story, contact form, and editable CMS source.

Deploy to GitHub

  1. Extract the ZIP; do not upload it unopened.
  2. Open macv0223/psalm-23-trasnportation on main.
  3. Upload the contents of the extracted folder to the repository root, replacing the old files.
  4. Include the hidden .github/ folder.
  5. For the quickest launch, use Settings → Pages → Deploy from a branch → main → /(root).
  6. View the new site.

For automatic updates after CMS edits, use GitHub Actions and configure the Cloudflare OAuth Worker. Full details are in docs/DEPLOY.md. The admin editor does not have live sign-in until configured.
