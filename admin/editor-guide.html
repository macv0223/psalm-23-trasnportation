FOR AUTHORIZED EDITORS

How to edit
your website.

You don't need to write any code. Sign in with your approved GitHub account, open Edit website, and select All website content.

  1. Change text: Expand Homepage hero, Transportation services, Our story, or Quote request form.
  2. Update services: Add, reorder, or delete entries in the Transportation services list.
  3. Update contacts: Open Branding & contact details to change phone or email. This updates all visible contact links and the quote-request message recipients.
  4. Replace images: Use the image selector to upload an approved file. Add a meaningful image description for accessibility.
  5. Save a draft: Save changes as a draft while you review the preview.
  6. Publish: Select the publish option when approved. The GitHub Pages website updates after the workflow finishes, usually within minutes.

The quote form opens a visitor's texting or email application; it does not send a message or store personal information on the website.

Only authorized GitHub users with repository write access can edit. Drafts and updates are recorded in GitHub history.
